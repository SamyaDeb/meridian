## Why a separate hosted config
Envio's docs ("Deploying Your Indexer", docs.envio.dev/docs/HyperIndex/hosted-service-deployment, read through search results because the sandbox can't open docs.envio.dev) say: the Config File path is relative to the Indexer Directory, the Root Directory is set in the indexer's settings (important for monorepos), keep every import inside the indexer directory, and the GitHub repo must be ≤ 100 MB (ours: ~72.5 MB of tracked files, git pack 60 MiB: OK, but don't commit large fixtures).
Two open Envio issues from 28 Sep 2026 describe monorepo pitfalls when the Root Directory is the repo root: Cloud runs `pnpm start` at the Root Directory (enviodev/hyperindex#1667) and reads the `envio` version from the Root Directory's `package.json` (#1666). Setting the Root Directory to `indexer/` avoids both: `indexer/package.json` has `"start": "envio start"` and `"envio": "3.12.1"`, and the indexer has no workspace dependencies.

3. **Indexer settings:**
   | Setting | Value |
   |---|---|
   | Indexer Directory / Root Directory | `indexer` |
   | Config File | `config.hosted.testnet.yaml` |
   | Branch | `ws-06g-hosted-envio` (or `main` once merged) |
   | Env vars | `ENVIO_API_TOKEN` only if step 1 says HyperSync needs it. Never commit it |
4. **Push / redeploy** and watch the build log. Expected: codegen OK, then sync from block 66,875,788.
   - "Failed to download" / "Missing config": the directory or config path is wrong (Envio docs); fix the setting, then push a new commit.
   - Install fails for lack of a lockfile in `indexer/` (> VERIFY: whether Cloud installs with `--frozen-lockfile`): generate one with `cd indexer && pnpm install --ignore-workspace --lockfile-only`, commit `indexer/pnpm-lock.yaml`, push.
5. **Smoke test** the GraphQL URL the dashboard shows (> VERIFY the exact URL format there; don't guess it):
   ```bash
   curl -s -X POST "$ENVIO_GRAPHQL_URL" -H 'content-type: application/json' \
     -d '{"query":"{ FundingCheckpoint(limit: 3, order_by: {blockNumber: desc}) { blockNumber cumFunding realizedApr1hWad } }"}'
   ```
   Expect rows with recent testnet blocks. Compare `realizedApr1hWad` with `averageFundingApr(12000)` the way `indexer/test/replay.test.ts` does.
6. **Wire the app:** set `NEXT_PUBLIC_INDEXER_URL=<GraphQL URL>` on the app's testnet build (Stats page reads it; `app/src/data/hooks.ts`). Record the URL in `docs/standup/C.md` and the write-up.
7. **Mainnet (CP3):** once `deployments/143.json` exists, `cd indexer && node scripts/gen-config.mjs 143 --hosted` → `config.hosted.mainnet.yaml`, commit, add a second hosted indexer with that config file.
